What do these results terms mean?
Held-out rows
Rows left out of training for the model that made those predictions.
Balanced accuracy
Find the share of rows correctly predicted within each class, then average those shares so each class counts equally.
Accuracy
The share of rows for which the model predicted the correct class.
Baseline
A reference score for judging how much the model improves on a simple rule.
Most frequent class
The baseline that always picks the commonest answer.
Random guesses by class share
The baseline that guesses according to how common each class is.
Percentage point
A unit for the difference between percentages, such as the five points from 75% to 80%.
Train–test gap
Training balanced accuracy minus held-out balanced accuracy for the same split. For Cross-Validation, average those differences across folds.
Standard deviation
Describes how far fold scores tend to spread around their mean.
Interquartile range
The width of the middle half of the fold scores.
Precision
Of the rows predicted to be in a class, the share that really belong to it.
Recall
Of the rows that actually belong to a class, the share that the model found.
F1
Combines precision and recall into one score that drops when either is low.
Macro-F1
Averages F1 equally across classes.
MCC
Matthews correlation coefficient. A score for how closely predicted and actual classes agree across correct predictions and errors. Higher values indicate stronger agreement.
ROC-AUC
Area under the receiver operating characteristic curve. Summarises how well the model ranks members of a class ahead of other rows across possible cutoffs.
Average precision
Summarises how precise the model's predictions are as the score cutoff changes and it finds more members of a class.
Log loss
Measures how much chance the model gave to the answers that actually happened. Confident wrong answers increase the loss sharply.
Brier score
Measures squared gaps between the model's predicted chances and what happened. Smaller gaps give a lower score.
Calibration
Checks whether predicted chances match how often the events happen.
ECE
Expected calibration error. Averages the gaps between predicted chances and observed outcomes across groups of predictions, giving larger groups more weight.
True class
The recorded answer for a row.
Predicted class
The model's answer for a row.
Confusion matrix
A table that counts each pairing of recorded and predicted answers.
Positive class
The category treated as the yes answer in a two-category check.
False positive
Predicting the positive answer when the actual answer is negative.
False negative
Missing the positive answer when it is present.
Probability threshold
The cutoff that turns a predicted chance into a yes-or-no decision for the positive class.
Fit time
Time spent training the model.
Fit + score across folds
Time spent training and evaluating the folds.
