Palmer Penguins · Target: species

Holdout evaluation

Manual training fits the development data and evaluates once on held-out test data.

Random Search fits training data and chooses parameters on validation data, then refits on development data before evaluating on the test data.

The validation fraction is measured against all eligible rows, not only the development rows.

Categorical features use categories learned from fitting data. Unknown held-out categories encode as all-zero. Numeric features are not scaled.
