# Implementation plans

Each substantive change has one plan here. The shared `agent-workflow` skills run the lifecycle: `/create-plan` writes and submits plans, `/verify-plan` reviews them, `/implement` executes them, and `/verify-implementation` audits and archives them. Closed plans live in `archive/`. Work that belongs in `web-ml` is requested in `../web-ml/specification/requests/`, not planned here (see the Repository boundary in `AGENTS.md`).

## Lifecycle

`stub` → `draft` → `ready-for-review` → `ready` → `implemented` → `archived`, enforced by `bun run plans:*`. See `agent-workflow/docs/WORKFLOW.md` for how to run each step.

Run `bun run plans:check` to validate every plan, this index and the spec index's status column.
